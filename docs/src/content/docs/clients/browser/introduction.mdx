The **`SignalClient`** is an EventEmitter interface used to communicate with the [Service](../../server/introduction). It facilitates both authentication and peer-to-peer communications through a variety of methods that can be executed manually.

## Installation

To install the SignalClient, run the following command:

```bash
npm install algorandfoundation/liquid-auth-js --save
````

## Get Started

<Aside>The service must be running as the origin server. See the [server integrations](../../server/integrations) documentation for more information.</Aside>

### Manual Integration

To manually integrate the `SignalClient`, use the following code snippet:

```typescript
//app.ts
import {SignalClient} from '@algorandfoundation/liquid-client';
const client = new SignalClient(window.origin);
```
