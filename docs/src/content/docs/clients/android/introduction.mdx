<Aside type="caution">
  Handling [Passkeys](../../guides/concepts#passkeys) in Android can be complex and requires careful planning for successful integration.
</Aside>

The Android Client is a library designed to allow you interact with the Liquid Auth Service, offering utilities for seamless integration with the native platform.

### Pre-requisites

- Install [Android Studio](https://developer.android.com/studio).
- Create or open an existing application project.

### Obtaining SHA256 Fingerprint

To enable the server to attest to the credentials, you need the SHA256 fingerprint of your application. Use the following command to retrieve it:


```bash
keytool -list -v -keystore <path> -alias <alias> -storepass <store_password> -keypass <key password>
```

<Aside>
  For production environments, ensure this fingerprint is shared with any services that will be verifying the credentials.
</Aside>


## Getting Started

You can either run a local instance or deploy the [Liquid Auth Service](../../../server/running-locally). Ensure you include the SHA256 fingerprint and application name in the [environment configuration](../../server/environment-variables).

### Install the Library

**Step 1: Add jitpack as a repository**

Choose the appropriate configuration file for your project.

<Tabs>
  <TabItem label="settings.gradle.kts">
    ```kotlin add={6} add={7} add={8}
    dependencyResolutionManagement {
        repositoriesMode.set(RepositoriesMode.FAIL_ON_PROJECT_REPOS)
        repositories {
          google()
          mavenCentral()
          maven {
            setUrl("https://jitpack.io")
          }
        }
    }
    ```
  </TabItem>
  <TabItem label="settings.gradle">
    ```groovy add={6}
    dependencyResolutionManagement {
      repositoriesMode.set(RepositoriesMode.FAIL_ON_PROJECT_REPOS)
      repositories {
        google()
        mavenCentral()
        maven { url 'https://jitpack.io' }
      }
    }
    ```
  </TabItem>
</Tabs>

**2. Install the Package**

Add the Liquid Auth dependency to your project.

<Tabs>
  <TabItem label="build.gradle.kts">

  <TabItem label="build.gradle">
