## Introduction

Liquid Auth provides users with comprehensive control over their data and privacy, addressing the prevalent issue of unnecessary intermediaries between end users and wallet providers.

By integrating the advanced security features of FIDO2/WebAuthn with the decentralized framework of WebRTC, Liquid Auth provides a secure and private communication channel for users to communicate.


### What is Liquid Auth?

Liquid Auth is a self-hosted authentication service that provides a simple way to associate Passkeys with KeyPairs commonly used in cryptocurrencies. Beyond authentication, Liquid Auth offers a peer-to-peer signaling service, enabling secure connections between users.

## Brief Technical Specifications

Liquid Auth leverages the latest advancements in security protocols:
- **FIDO2/WebAuthn:** Provides strong, passwordless authentication, reducing the risk of phishing attacks.
- **WebRTC:** Enables direct peer-to-peer communication, minimizing latency and enhancing user experience.

For full details of the architecture, please refer to [architecture.md](architecture.md).

## Use Cases

Here are a few notable use cases for Liquid Auth that show that it could be used in various applications:

- **Decentralized cryptocurrency wallets:** Users can securely manage their crypto assets without depending on third-party wallet providers.

- **Privacy-focused messaging applications:** The peer-to-peer signaling service can be used to enable end-to-end encrypted communication.

- **Decentralized identity management:** Companies can set up a self-sovereign identity system for their users.

- **DeFi (Decentralized Finance) platforms:** Improve security and user control in decentralized exchanges and lending platforms.

- **NFT marketplaces:** Provide secure authentication and transactions for the purchase, sale, and trading digital assets.
